# `mirage-tls-win32-x64-msvc`

This is the **x86_64-pc-windows-msvc** native binary for [`mirage-tls`](https://www.npmjs.com/package/mirage-tls).
Do not install it directly: `npm install mirage-tls` pulls in the right one for your platform.

The binary statically links BoringSSL and other third-party code; see `LICENSE` and
`THIRD_PARTY_NOTICES.md` in this package.
